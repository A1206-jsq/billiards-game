# 8 球台球小游戏

## 运行

直接用浏览器打开 `index.html`，或在项目目录运行：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000`。

## 已实现

- 固定时间步物理循环，减少不同电脑刷新率造成的差异
- 球与球的弹性碰撞、桌边反弹和摩擦减速
- 6 个袋口、进袋判定和白球重置
- 8 球规则：全色/花色分组、轮流击球、继续击球、犯规换手
- 犯规后自由球（点击“放置白球”后点击桌面）
- 8 号球提前落袋判负，清空目标球后合法打入 8 号球获胜
- 响应式界面，支持鼠标和触摸拖拽

这是一个适合练习的简化 8 球规则实现；正式比赛还会涉及开球规则、同时落袋、推杆、接触库边等更细节的裁判规则。
